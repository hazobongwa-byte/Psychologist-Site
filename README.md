# Bongi Ndumo — Psychologist website

A calm, static website for a private psychology practice. Colour, type, and motion are chosen to feel safe, unhurried, and trustworthy.

Live page: [https://hazobongwa-byte.github.io/Psychologist-Site/](https://hazobongwa-byte.github.io/Psychologist-Site/)

## Stack

- HTML, CSS, and a little JavaScript
- Google Fonts: Playfair Display and Nunito Sans
- Hosted with GitHub Pages

## View it

Open `index.html` in a browser, or visit the GitHub Pages link above after pushing to `main`.

GitHub Pages should be set to **Deploy from a branch** → `main` → `/ (root)`.
